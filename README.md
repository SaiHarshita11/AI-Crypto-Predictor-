# 🧠 AI-Driven Cryptocurrency Predictor (Infosys Internship Project)

 
**Title:** AI-Driven Cryptocurrency Price Forecasting using Flask and LSTM  

---

## 🚀 Project Overview
This project aims to predict cryptocurrency prices using **LSTM (Long Short-Term Memory)** neural networks integrated with a **Flask web interface**.  
It provides a user-friendly dashboard to forecast prices for top cryptocurrencies like BTC, ETH, BNB, and others.

---

## 🧩 Features
- Real-time cryptocurrency price forecasting  
- Flask-based backend with REST API  
- LSTM deep learning model using TensorFlow/Keras  
- Interactive dashboard for predictions and analytics  
- Prediction history stored in SQLite database  
- Download predictions as CSV  

---

## ⚙️ Tech Stack
**Frontend:** HTML, CSS, JavaScript  
**Backend:** Flask, Flask-SQLAlchemy, Flask-CORS  
**Machine Learning:** TensorFlow/Keras, scikit-learn, NumPy, Pandas  
**Database:** SQLite  
**Data Source:** Binance API via `python-binance`
